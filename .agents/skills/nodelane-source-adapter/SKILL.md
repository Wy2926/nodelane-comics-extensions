# 网站来源适配

交付可安装、可阅读且验证范围明确的来源。先复用可用实现，只改站点需要的代码。

## 定位与选路

本技能随 `nodelane-comics-extensions` 维护；通过符号链接加载时，先解析本文件真实路径，以下链接均相对真实文件。读取两仓库的 `AGENTS.md`；插件根目录由本文件所在目录向上三级确定，App 路径从当前项目或用户上下文确认，不假定它们相邻。普通构建与 CI 互不依赖。

按域名、旧域名和站名检查本仓库 `src/`、`repository.json`、活动目录，再检索 [Keiyoushi 源码](https://github.com/keiyoushi/extensions-source)与[原版扩展](https://github.com/keiyoushi/extensions)。核对当前域名、具体来源 ID、版本和许可，实测原扩展；目录有名字、主页可打开或热门列表成功都不等于可读。

| 证据 | 最小改动位置 |
| --- | --- |
| 原版 APK 可用 | 插件仓库保存原包和元数据，不翻译成 JS |
| 原版失败，已定位为宿主兼容问题 | App 既有 Mihon 通用桥；先找全部调用者并补故障回归 |
| 原版失败，已定位为上游站点解析问题 | 基于上游最小修复并保留来源与许可，不另写等价解析器 |
| 本仓库已有 JS 来源需要维护 | 在该站点目录修复，复用当前 MProvider 契约 |
| 缺少可用实现，或必须更换运行类型 | 给出实测证据、最小方案和数据影响，按本次已授权范围推进，不默认引入新运行时 |

浏览器项目 `node-comics` 仅在有可复用协议证据时参考，先读其 README；不复制浏览器运行时，不成为构建依赖。既有 JS 个例不是将所有原版 APK 重写为 JS 的理由。

## 实现落点

开始编辑前，列清本次涉及的站点文件、注册记录、测试／样本、许可与调用方；检查现有作品 URL、章节身份和进度是否受影响。

- **原版 APK**：按 [契约](../../../docs/CONTRACT.md#原版-apk-与同来源升级)和 `scripts/catalog.mjs` 的 `validateManifest` 填写清单。可参考 `repo/sources/comix/0.3.0/manifest.json` 的格式，但它只是历史 APK 示例；不得复制其身份、域名或验收结论。保存 APK、原始 LICENSE、固定源码提交、下载地址、版本、大小和 SHA-256；`mihonSourceId` 保持字符串。构建只校验并复制，不下载或改写 APK。
- **已有 JS**：先读本站 README 与实现，再按需读契约中的接口、请求和图片处理部分。沿用 `manifest.files` 打包；简单修复不增加 parser、wrapper 或共享框架。多个实际站点确实需要同段实现时才提取共享代码。
- **宿主能力**：读取 App 的 `docs/SOURCE_PLUGINS.md` 定位入口。域名、选择器、签名和站点图片参数留在插件；App 只处理通用运行、网络、图片和生命周期。已有接口能表达就不新增能力；确需新增时同时更新有版本的能力声明、两端契约及回归。翻译、账号和计费不参与来源解析。

永久 ID 只分配一次，已发布代码修改必须升版；旧包及对应源码、许可不可覆盖或删除。切换运行类型时，保留 ID 不代表旧 URL 自动兼容，不偷偷删除书籍或添加迁移。新增待验收来源使用 `enabled: false`；为本地联调启用时，不顺带推广正式目录。分类、收费和成人标记按可核实事实填写，未知不猜。

目录分页成功后才交付完整结果；验证、限流、解析错误不能伪装空列表。保留特殊章、完整身份 URL、上传时间语义、图片顺序和重复页槽。请求、分页、重试与 WebView 有结束和释放条件；不用固定睡眠猜测网页就绪，不增加随意截断目录的数量限制。复用宿主请求边界，不新增图片 CDN、存储桶或路径白名单。

## 验证与交付

在插件根目录运行 `npm run check`。新增非平凡逻辑或修复留一个能覆盖实际行为的最小回归；优先扩展现有用例，样本使用合成或脱敏数据，不新增只核对代码措辞的测试。

- JS：补充 `test/fixtures/contracts.json` 中受影响的输入／输出，经 `npm run test:app -- --app /明确的App绝对路径` 验证实际 QuickJS／DOM 桥。网页执行另复用相应契约测试；Node DOM 通过不能替代 App 桥通过。命令也运行现有 Comix 桥测试，必要时用 `FLUTTER` 指定已安装且匹配 App 依赖的 SDK。
- APK：本仓库检查验证包和目录；QuickJS 测试不能执行 APK。用 App 的 Mihon 桥验证实际原包，宿主改动运行对应 Flutter 回归。
- 真实阅读：从目录安装／更新，检查热门、搜索及分页、完整目录、首尾图片、跨章、失败后重试、后台恢复和页码保持。Android 与 iOS 分别记录，模拟器、真机和真实服务不混写。验证受阻时保留具体失败证据，继续可完成的离线工作，不宣称站点已支持。

网络实测低并发且有超时；日志只保留计数与脱敏错误，临时样本／截图放忽略的 `artifacts/`，不提交 Cookie、账号、私密响应或签名图片 URL。

在本站 README 只维护当前支持范围、必要运行说明和未验收项；来源与许可归入 `THIRD_PARTY.md`。删本次范围内被替代的工作源码和重复说明，保留必要回归与不可变归档。发布、渠道推广、恢复与本地联调按 [维护说明](../../../docs/MAINTENANCE.md)；技能本身不授予提交、推送或发布权限。

完成时简述实现位置、真实通过的检查、未验收平台和数据兼容风险。不要把 APK 摘要通过、模拟响应或清单返回成功写成正文阅读验收。
