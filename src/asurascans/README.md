# Asura Scans

支持 `https://asurascans.com` 的英文漫画：热门、最新、关键词搜索，排序／状态／类型／多题材／作者／画师／最少章节数组合筛选，作品资料、完整目录、上传日期和免费章节图片。图标取自网站，来源标签为韩漫、国漫、条漫、改编、部分收费；最低 App 版本为 `0.1.0`。

列表使用 `api.asurascans.com/api/series`，每页 20 部。搜索无结果时 API 返回 `data:null`，尾页省略 `has_more`；以有效分页元数据区分空结果与请求失败。详情与阅读页解析 Astro 序列化数据，不执行网站脚本。作者、画师输入使用网站名称。列表、详情、正文各一次主请求，站点稳定地址可能发生跳转；不额外下载筛选全集、不轮询、不缓存页面或失败结果。

保存 `/comics/<seriesSlug>` 及 `/chapter/<number>` 稳定地址，由网站跳转到当前后缀；页面归属按作品和章节数据核验，不依赖展示地址的固定格式。请求保留查询参数，来源 ID 支持 URL 编码。完整目录按源站总数校验，保留 0 话、小数话及付费／提前阅读章节，以 🔒 标记受限章节。日期优先 `published_at`，其次有效 `created_at`，未知返回空字符串。图片接受源站返回的 HTTP(S) 地址，不限制 CDN 主机或路径，保留查询参数和重复页槽。

受限正文明确提示付费或等待提前阅读期，不返回预览或空成功；未实现账号令牌与付费 API。当前免费正文实测为普通图片。上游历史 `tiles` 分块图片不属于现有 App 图片契约，遇到时明确提示尚未支持，不错误套用另一算法。若源站重新启用，需要增加通用、有版本的 App 图块映射能力后再适配。CF 验证由设备网页处理，插件只区分验证、封禁、限流和解析错误。

实现移植自 Keiyoushi，保留 Apache-2.0 原文；固定版本和摘要见 [THIRD_PARTY.md](../../THIRD_PARTY.md)。Mangayomi 的旧站实现已实测不适用于当前页面。

```sh
npm run check
npm run test:app -- /明确选择的App路径
```

合成样本覆盖组合筛选、空结果／尾页、Astro 数据、目录完整性、日期、锁定章节、归属、重复图片、任意图片主机及错误后重试；使用同一组样本验证 App QuickJS 和原生 DOM。真实 HTTP 与原生解析验证包括 Cyberpunk Chivalry 的完整目录、第一／二话，Overgeared 的完整目录和旧章节，以及受限章节错误；抽查各章首尾图片均能读取。iOS 27 模拟器已验证来源卡片、热门、搜索、详情、日期、第一话首尾图片及第二话切换／显示。Android 与真机尚未验收。
