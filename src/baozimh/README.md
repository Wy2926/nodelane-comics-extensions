# 包子漫画

主站 [cn.baozimh.com](https://cn.baozimh.com/)，中文。基于 Keiyoushi Baozi 协议移植，固定提交与许可见 [THIRD_PARTY](../../THIRD_PARTY.md)。无上游运行时依赖。

- 热门使用分类 API，按源站 `next` 判断翻页；最新对应“最新上架”。关键词搜索单页，地区、状态、题材、首字母筛选仅用于无关键词浏览。
- 详情接受源站元数据明确关联的新旧作品地址；目录包含页面内隐藏的全部章节，也支持仅有“最新章节”的短目录，并保持最新章在前。存在“查看全部”时核对总数，缺少完整目录不使用最新章节预览代替。保留零话、番外及查询参数，只按完整 URL 去重。源站仅给最新章的更新时间，其他日期保持未知；被屏蔽作品明确报错。
- 列表、作品和已保存的章节 URL 保持不变；正文及后续分页按章节身份请求 `tw.twbzmg.com`。按页码和下一页链接读取整话，校验章节及分页身份，失败不返回半话。图片顺序和重复页位保持不变，不限制 CDN、存储桶或路径。对站点自动分配的图片域名，按网站公开节点以 HEAD 检查可用线路，解析章节清单时重新选择，保留分片、路径和查询参数；未识别域名及全部探测失败时保留源站地址。
- 已缓存的章节可在阅读器菜单选择“刷新”重新解析并选线；图片上的“重试”仅重试当前图片地址。
- 普通请求遇到 Gatekeeper 时，通过 App 的 `evaluateJavascriptViaWebview` 打开临时隐藏网页，由源站自身脚本完成验证，再在同一网页会话读取原请求。支持分类 API 单独验证；不提取或保存 Cookie。单个插件实例的验证请求串行执行，验证状态最多等待 150 秒，后续请求限时 25 秒，宿主网页总限时 180 秒。返回结果后网页销毁；再次被拦截、验证失败和超时明确报错，不循环重试。
- Cloudflare 或需要人工操作的验证仍在来源网页处理后重试。隐藏网页无法切换为可见验证窗口；不支持上游 App 镜像、图片裁切或替换缺失图片。

兼容 NodeLane App 0.1.0 及以上，更新插件即可使用，无需修改 App 或安装 Keiyoushi APK。

验证范围：Node／App QuickJS 与原生 DOM 覆盖长短目录、验证回退、旧章节入口、整话分页、重复页位、失败和重试。全新 Edge 会话实测 Gatekeeper 验证接口返回 `passed` 后完成目录读取。MuMu Android 12、App 0.1.2（6003）的真实临时网页桥已验证热门、最新和五部作品目录；《转生的典范》得到 11 章，序章和第 10 话的正文清单及首尾图片通过真实 HTTP 检查。当前变更尚未验收 iOS、真机、插件内升级和阅读器完整交互；站点验证和封面可达性取决于设备网络与会话。
