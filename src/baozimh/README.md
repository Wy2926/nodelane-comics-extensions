# 包子漫画

主站 [cn.baozimh.com](https://cn.baozimh.com/)，中文。基于 Keiyoushi Baozi 协议移植，固定提交与许可见 [THIRD_PARTY](../../THIRD_PARTY.md)。无上游运行时依赖。

- 热门使用分类 API，按源站 `next` 判断翻页；最新对应“最新上架”。关键词搜索单页，地区、状态、题材、首字母筛选仅用于无关键词浏览。
- 详情接受源站元数据明确关联的新旧作品地址；目录包含页面内隐藏的全部章节，保留零话、番外及查询参数，只按完整 URL 去重。源站仅给最新章的更新时间，其他日期保持未知；被屏蔽作品明确报错。
- 列表、作品和已保存的章节 URL 保持不变；正文及后续分页按章节身份请求 `tw.twbzmg.com`。按页码和下一页链接读取整话，校验章节及分页身份，失败不返回半话。图片顺序和重复页位保持不变，不限制 CDN、存储桶或路径。对站点自动分配的图片域名，按网站公开节点以 HEAD 检查可用线路，解析章节清单时重新选择，保留分片、路径和查询参数；未识别域名及全部探测失败时保留源站地址。
- 已缓存的章节可在阅读器菜单选择“刷新”重新解析并选线；图片上的“重试”仅重试当前图片地址。
- 主站 Gatekeeper 与 Cloudflare 需要 App 来源网页会话，验证后重试。分类 API 可能单独要求验证，首页能打开不代表分类接口已放行。插件不自动解题；不支持上游 App 镜像、图片裁切或替换缺失图片。

兼容 NodeLane App 0.1.0 及以上，更新插件即可使用，无需修改 App 或安装 Keiyoushi APK。

验证范围：Node／App QuickJS 覆盖旧章节入口、整话分页、重复页位、失败和重试；真实 HTTP 验证正文首尾图片。MuMu Android 12 覆盖插件更新、热门与中文搜索、完整目录、页漫及条漫正文、跨章阅读和后台页码恢复。当前阅读域名尚未复测 iOS、真机与翻译服务；站点验证和封面可达性取决于设备网络与会话。
