# BatCave

[BatCave](https://batcave.biz/) 英文漫画 JS 来源，永久 ID `86001028`。热门按评分排序；最新和关键词搜索按站点翻页。目录读取完整章节数据，保留年刊、特别篇和源站日期；正文按声明页数取图，保留重复页，排除末尾推广图。

支持 `browser.manga-preview.v1`：在作品页、阅读页或长按站内卡片时识别所属作品；从站外长按本站链接时，仅按目标 URL 读取摘要。若提示站点验证，请先在 App 内置浏览器打开 BatCave，完成后返回重试。

在 App 内置浏览器点底部的「漫画」，或长按作品卡片，选择「加入书架」。收藏后，同一入口会显示「用 App 阅读器打开」。如果弹窗只有封面和书名，需要更新到包含[浏览器书架操作](https://github.com/Wy2926/node-comics-app/commit/d0bf5da3)的 App；只更新来源插件不会新增这两个按钮。

**本地试用：** `npm run build`，从 [本地测试目录](../../docs/SOURCE_PORTS.md) 安装。当前未启用渠道分发。[协议来源与许可](../../THIRD_PARTY.md#batcave-js-来源)。

**验证范围：** Node 合成回归与 App QuickJS／DOM 契约已通过。MuMu Android 12 从本地目录安装 JS 后，实测热门、最新、关键词搜索和《Se7en》的 7 章目录；第 6 期正文可读，切至第 7 期后回到桌面再打开，页位为 `2 / 32`。在内置浏览器从《Absolute Martian Manhunter》作品页加入书架，工具栏和长按章节链接均能打开同一收藏的 App 阅读器；冷启动后书架仍保留该作品。

**已知边界：** 同一个无匹配关键词，站点在可见浏览器中显示零结果，向 App 的 HTTP 客户端却返回了没有结果标记的 404；插件将这种响应报为请求失败。桌面直接 HTTP 和 MuMu 的 Keiyoushi 原包热门请求也遇到过 403。iOS、Android 真机与断网重试尚未验收。
