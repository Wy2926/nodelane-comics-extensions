# FEEL web

日语免费页漫。JS 移植 Keiyoushi Feel Web，支持刊物筛选、热门、最新和关键词分页。已结束公开的章节默认留在目录中，可在来源设置中隐藏。公开正文需要 App 的 `image.tile-transpose.v1`。

真实 HTTP 已核对热门、最新、搜索及空结果。《あした、君と恋を知る》4 话与源站、原包一致，前两话分别为 36、37 页，均取得首尾 JPEG。App QuickJS 已验证阅读页 DOM、重复页位与还原声明。

MuMu Android 12 x86_64 从本地目录安装 JS，在 App 内从第 1 话读到第 2 话末页，退到桌面再打开仍为 `19 / 37`。另查《きちじつごよみ》8 话中有 6 话停止公开，JS 明确报错，随后仍能读取公开话。iOS、ARM 真机和离线下载未验收。
