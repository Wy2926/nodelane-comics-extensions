# Hachiraw

NodeLane JS 来源首版 `0.1.0`，来源 ID 为 `86001011`。支持热门、最新、关键词搜索及分页、详情、完整章节目录和正文图片。实现来源与 GPL-3.0-only 许可见仓库 `THIRD_PARTY.md`。

使用完整作品／章节 URL，保留隐藏章节、修正版、独立章节身份及重复正文页位。排除源站 `01.png` 推广图后，按站点声明的正文页数校验完整性。

复用 App 临时隐藏 WebView：列表和详情读取已加载页面，正文在作品页同源请求，不预加载整章图片。图片请求携带该设备 WebView 的实际 User-Agent 与来源 Referer。验证和请求均有超时，结束后由宿主释放页面；CF 未自动放行时，在 App 浏览器完成验证后重试。

## 验证边界

- Node 回归覆盖解析完整性、分页、验证超时和失败后重试；App 契约验证真实 QuickJS 序列化、页面程序执行及结果反序列化。
- Android API 36 ARM 与 iOS 27 模拟器已验证真实列表、搜索分页、275 章目录、正文图片、跨章及后台恢复；iOS 验证退出重进保留页码。抽查《呪術廻戦》第 1、2、3、271 章正文分别为 54、25、23、22 页；其首尾图片使用两端返回的实际请求头在桌面下载并解码。
- 真机、长时间阅读、网络切换和交互式验证尚未验收；不保证所有 CF 挑战自动通过。
