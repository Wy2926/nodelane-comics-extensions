# 嬉皮漫畫

[m.hipmh.com](https://m.hipmh.com/) 的 NodeLane JS 来源，永久 ID `86001027`。在 App 的「来源」中刷新 [NodeLane 官方正式目录](https://comics-extensions.nodelane.net/stable/index.json)，即可安装「嬉皮漫畫」。

- 人气榜、最近更新和关键词搜索均支持分页。留空关键词可组合排序、地区、连载状态和热门题材。搜索别名使用同一作品链接；源站搜索中残留的已删除作品会报 404。
- 目录按源站倒序取全，保留番外、公告和同名章节。日期取源站章节创建时间，未知留空。正文由网站阅读器选择线路并生成图片清单，再按页位交给 App。

**验证范围：** Node 合成样本和 App QuickJS／网页桥测试覆盖搜索、目录中断重试、章节归属、重复图片和不完整页序。真实 HTTP 核对了热门和搜索前两页、最新、组合筛选、空结果及多页目录。

Android 12 MuMu 从本地目录安装 JS，实测 164 章作品，连续两章（65 页、60 页）首尾图片和跨章阅读；切到后台再返回仍停在第 21 页。断网抽查命中已预加载章节，未验证冷启动读章失败后的重试。iOS 与 Android ARM 真机尚未验收。[协议来源与许可](../../THIRD_PARTY.md#嬉皮漫畫-js-来源)。
