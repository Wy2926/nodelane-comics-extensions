## 旧 JS 数据

来源 ID 不变，但 URL 契约不同：JS 保存完整 `https://18comic.vip/album/<id>/` 和带 `album_id` 的章节网址，APK 使用 `/album/<id>`、`/photo/<id>` 内部路径。实测旧作品网址导致详情／目录报错，旧章节网址返回空页；改回原生内部路径可恢复请求。

已有 JS 书籍需从 APK 重新搜索添加，阅读位置手动衔接；本次不迁移或删除书籍、章节与进度。已安装 JS 不会因目录撤下而自动卸载。
