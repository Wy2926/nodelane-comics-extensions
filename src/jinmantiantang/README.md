# 禁漫天堂

`https://18comic.vip/` 的本地 JavaScript 来源，永久 ID `86001014`。通过 `www.cdngwc.net` 的公开 API 提供热门、最新、关键词／JM 编号搜索、排序、完整章节目录及正文图片；源码和运行不依赖 APK 或相邻仓库。

- 章节使用 `/photo/<id>?album_id=<作品ID>` 保存归属；正文交叉核对作品、章节、总页数和页序，保留重复图片页槽。目录保留源站特殊章名；仅末章使用接口已知的更新时间，其余日期明确未知。
- API 请求和解码在 QuickJS／App 通用桥完成。图片条带数量由插件计算，App 执行还原并保留 GIF 动画；无须登录，账号功能不在本插件范围。
- 需 App 声明 `crypto.md5.v1`、`crypto.aes-ecb.v1`、`image.strip-reverse.v1`。旧 App 会拒绝安装；`0.1.0` 分发于 `stable`，验收范围见下。新增来源没有已有书籍需要迁移。
- API 当前使用固定上游节点；节点或加密协议变更时请求会明确失败，需要更新来源。网页入口自身的 Cloudflare 验证不等于 API 阅读失败。

运行沿用根目录 `npm run check` 和 `npm run test:app -- --app <App绝对路径>`。来源和许可见根目录 `THIRD_PARTY.md`。

## 验证边界

- Node 合成样本：加密响应、分页、空结果、完整目录、身份与页数错误、切片参数、失败后重试和实例隔离。
- App QuickJS 合成契约：真实 MD5／AES-ECB 桥、UTF-8、目录日期、条带参数序列化和解码失败；通用 HTTP 桥兼容响应 MIME 末尾分号，图片层兼容静态 WebP 的零帧表。
- Node 真实 HTTP：热门与关键词搜索各两页、最新列表、357 章目录，两个章节的 125／89 页清单及首尾图片下载。
- Dart 真实图片：720×4200 图片还原后与原版 APK 输出对照，RGB 平均绝对误差约 0.36（未还原约 42.75）；GIF 动画透传由合成样本验证。
- Android MuMu、本地 JS 包：从本地目录安装，热门／最新、JM 编号搜索、357 章目录、125 页章节首末页、跨章与后台返回第 5 页保持通过。
- iOS、真机、完整离线下载、进程终止后的恢复待验收；正式渠道分发不代表这些范围已经通过验收。
