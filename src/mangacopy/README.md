# 拷贝漫画

中文免费漫画。`mangacopy.com` 与 `copy4000.com` 为同一来源，保持原版扩展的作品、分组和章节标识。目录与阅读沿用 Keiyoushi 原包，不导入浏览器书架。

正文需要 Android Mihon 桥保留原包为阅读页设置的桌面 `User-Agent`。旧桥会用 WebView 的移动身份覆盖它，导致网页标签可读、App 阅读器却取不到页图。修复在 App 宿主；已安装的原包、作品和章节地址无需变更。

MuMu Android 12 x86_64：兼容桥已验证热门、最新及中文搜索前两页、空结果和第 1／2 卷首尾图。覆盖安装修复版 App 后，已有来源可搜到《迷宮飯》82 条目录；`www.copy4000.com` 的第 94 话可读到 `20 / 20`，「动画化」可读到 `1 / 1`，默认 `www.mangacopy.com` 的第 91 话读到 `39 / 39`。

仅在含宿主修复的本地 Android 构建验收；iOS、ARM 真机和离线下载未验证。
