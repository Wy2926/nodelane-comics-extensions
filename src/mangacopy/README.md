# 拷贝漫画

中文免费漫画。`mangacopy.com` 与 `copy4000.com` 为同一来源，保持原版扩展的作品、分组和章节标识。目录与阅读沿用 Keiyoushi 原包，不导入浏览器书架。

MuMu Android 12 x86_64 的 NodeLane Mihon 桥已验证热门、最新与中文搜索前两页及无结果搜索。《迷宮飯》目录含 82 个不同章节标识；第 1、2 卷各 191、201 页，首尾图在设备上返回 JPEG。

App 从本地目录安装后，搜索与 82 条目录可用。阅读器打开「动画化」和第 94 话失败；重试第 94 话、切换 `www.copy4000.com` 均未恢复，而同台设备直接调用兼容桥可取得第 94 话的 20 页。保留在本地构建，待读取失败原因定位后再验收；iOS、ARM 真机和离线下载未验证。
