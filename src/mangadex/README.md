# MangaDex

使用原包中的 **All languages** 来源。同作不同语言、译组的发布保留各自章节地址，译组栏的 `[语言]` 前缀可用来区分。热门、最新和搜索由公开 API 提供；只有站内可用章节作为阅读验收样本。

MuMu Android 12 x86_64 的 NodeLane Mihon 桥已验证热门、最新、搜索前两页与空结果。《非人哉》（Fei Ren Zai / Non-Human）多语来源返回 815 个不同章节标识，包含英、印尼、越、波兰语；英语子来源仅 685 个，因此目录绑定多语 ID。设备已取得相邻发布的首尾 PNG／JPEG。

MangaDex API 会向使用浏览器身份的请求返回验证提示（HTTP 403）。Android Mihon 桥应保留原版 APK 自己的客户端 `User-Agent`；站点仍要求交互验证时，在来源网页按提示处理。此来源不需要切换运行类型。

MuMu 覆盖安装修复版 App 后，原有多语 APK 的热门、最新和 `Non-Human` 搜索均可用；App 内打开《非人哉》815 条目录，正文可读到 `5 / 5` 并切换到相邻发布。测试未遇到需手动完成的挑战。仅在含宿主修复的本地 Android 构建验收；外链、iOS、ARM 真机及离线下载未验证。
