# MangaDex

使用原包中的 **All languages** 来源。同作不同语言、译组的发布保留各自章节地址，译组栏的 `[语言]` 前缀可用来区分。热门、最新和搜索由公开 API 提供；只有站内可用章节作为阅读验收样本。

MuMu Android 12 x86_64 的 NodeLane Mihon 桥已验证热门、最新、搜索前两页与空结果。《非人哉》（Fei Ren Zai / Non-Human）多语来源返回 815 个不同章节标识，包含英、印尼、越、波兰语；英语子来源仅 685 个，因此目录绑定多语 ID。设备已取得相邻发布的首尾 PNG／JPEG。

App 从本地目录成功安装，但从来源页打开热门或搜索时，本站 API 返回 HTTP 403。直接调用同台兼容桥的结果不能替代 App 内阅读验收；来源保持待验收。外链、iOS、ARM 真机及离线下载未验证。
