# MangaDNA

免费英文条漫。使用 Keiyoushi MangaDNA 原包的英语来源，与浏览器适配的阅读语言一致。热门、最新、搜索和目录均由扩展获取。

MuMu Android 12 x86_64 的 NodeLane Mihon 桥已验证热门、最新、搜索前两页及无结果搜索。抽查 140 条目录和连续两章（19、10 页），两章首尾均取得 JPEG。

App 从本地目录安装后，搜索 `Return` 可打开《Return of the Martial Arts Genius》并读到第一章 `19 / 19`。读到章尾再点下一章时未稳定定位到第二章；章节选择与恢复仍待验收。iOS、ARM 真机及离线下载未验证。
