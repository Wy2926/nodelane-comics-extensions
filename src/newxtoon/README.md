# New XTOON

面向 `https://newxtoon5.com` 的自研 MProvider JavaScript 插件，韩文来源，含成人分类。代码与协议、许可依据见 [第三方声明](../../THIRD_PARTY.md)。

## 功能

- 热门、最新、关键词搜索与列表分页；空关键词时可选一般／BL·GL／成人分类。
- 详情、作者、题材、连载状态；逐页读取章节 JSON，并核对 HTML 链接归属、总数和分页状态。
- 保留特殊章、同名不同 URL 章节及原上传日期；目录中途失败整体报错，重试重新抓取。
- 读取正文图片页位，排除页面广告，保留重复图片页槽和源站图片地址。

构建与测试沿用仓库根目录的 `npm run check`、`npm run test:app -- --app <App绝对路径>`。
