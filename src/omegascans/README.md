# Omega Scans

`https://omegascans.org` 的英文漫画来源（含 18+ 内容）。NodeLane `0.1.0`，永久 ID `86001015`。使用 MProvider JavaScript 复刻 Keiyoushi 的公开阅读流程；[来源与许可](../../THIRD_PARTY.md#omega-scans-js-移植)。

- 热门、最新、关键词搜索与分页；状态、排序方向和多选题材可组合。题材来自源站 `/tags`，随插件更新。
- 作品及章节链接保留 slug 和数字 ID。目录按作品 ID 逐页获取，核对归属与总数后返回；保留同名不同章、特殊章和上传日期。
- 默认仅显示已发布的免费章。在来源设置打开「显示付费章节」后刷新作品目录即可看到锁章；插件不需要账号，锁章不可匿名阅读。
- 正文保留图片顺序、重复页位和源站地址参数。验证、限流、付费与缺失图片分别报错。

在 App 中刷新 [NodeLane 正式目录](https://comics-extensions.nodelane.net/stable/index.json)即可安装。本地运行 `npm run check` 后，测试目录为 `.build/index.json`，安装包为 `.build/packages/omegascans/0.1.0.js`。
