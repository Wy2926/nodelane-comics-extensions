# Pixiv

漫画日榜、最新漫画和标签搜索支持分页；搜索框也接受完整的 Pixiv 投稿或漫画系列网址。支持静态插画、多页漫画及系列，按源站目录和页序读取原图。动图（Ugoira）未适配。

需要登录时，在支持 GeckoView 的 Android 版 App 浏览器打开 `https://www.pixiv.net/` 登录，再返回来源重试。插件不收账号密码；只使用 Pixiv 为当前访问者返回的作品和图片，不推测被遮挡或缺失的原图地址。

在 App 刷新[正式目录](https://comics-extensions.nodelane.net/stable/index.json)即可安装，永久 ID `86001026`。MuMu Android 12 x86_64 从目录安装 JS，实测移动榜单、最新、标签搜索及公开投稿两页原图。关闭全部 Pixiv 标签后，来源仍能读取真实账号的关注动态；从来源搜索一篇 Pixiv 标记为「仅登录用户可浏览」的投稿，打开详情，阅读器显示其单页原图。同设备匿名访问这篇投稿，只能取得详情元数据，页清单返回 HTTP 404。

另用真实 HTTP 核对一个 14 章系列，连续两章各 7 页，四张首尾 PNG 原图均可取得。原版 Keiyoushi 1.6.1（英文来源）也通过 Mihon 桥解码了公开章节的首尾页。合成样本覆盖系列分页、归属、登录受限后重试及重复页位。iOS 和 Android ARM 真机尚未验收。
