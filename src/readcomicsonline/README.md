# Read Comics Online

面向 `https://readcomicsonline.ru`，永久 ID `86001006`，英文欧美漫画。来源卡片标注欧美、页漫、原创／改编和免费阅读。图标引用 Mangayomi 固定版本中公开的站点图标，避免源站 favicon 的 CF 验证影响加载。

按仓库流程先检索 Keiyoushi 与 Mangayomi，并在真实网页验证 Keiyoushi 新版选择器、请求地址、分页及章节首尾图片，再移植为 NodeLane JavaScript。固定提交、摘要与 Apache-2.0 原文位置见 [THIRD_PARTY.md](../../THIRD_PARTY.md)。不依赖 Kotlin、APK 或上游主题运行库。

热门和最新使用 `/comic-list?sort=views|latest`；搜索使用 `/advanced-search`，支持名称、连载状态、漫画类型及出版社。空关键词、无筛选时浏览热门。分页保留全部条件，明确的零结果才能返回空列表。每次列表、详情或章节读取只需一条 GET，没有目录缓存、全章图片预下载或无限重试。

详情读取页面的完整章节目录，保留年刊、小数编号、特别版及同名但不同 URL 的章节，按完整规范化 URL 去重。章节先核对作品归属；上传日期支持 `d MMM yyyy`，按设备本地日历转为毫秒字符串，缺失或非法日期返回空字符串。遇到尚未加载或出现未知分页的目录明确失败，不返回半份目录。

阅读器直接读取 `#reader-all` 的完整图片清单，核对 canonical、作品导航、当前章节以及逐页导航数量／顺序。图片按该阅读页给出的 HTTP(S) 地址读取，不限定 CDN 域名或图片路径；保留页槽及重复图片 URL，并带本站 Referer。无需新增图片处理能力。分类错误使用 `[RCO:类型]`，区分验证、限流、访问拒绝、身份、目录和图片故障。

CF 使用 App 的设备网页入口及其 Cookie／UA 管理。若首次打开后列表未加载，点“在浏览器打开”，待网站正常显示后返回并重试；插件不复制浏览器凭据，也不提供外部验证代理。

## 验证边界

| 层级 | 已验证 | 限制 |
| --- | --- | --- |
| Node 与 App QuickJS／DOM 桥 | 列表／搜索、原生筛选、缺封面、分页、完整目录、日期、重复页槽和分类错误 | 合成样本不代表站点随时可用 |
| 真实浏览器 | 热门／最新、搜索首页与末页、三个筛选参数、空结果、年刊／特别版／合订本目录及完整图片清单 | 无设备会话的直接 HTTP／图片请求会遇到 CF；大篇幅合订本仅检查清单，未进行移动端性能验收 |
| iOS 27 模拟器 | 安装与卡片资料、设备网页自动验证后复用会话、筛选搜索、完整目录及日期、首尾图片、下一话和后台位置保持 | 真机、Android 和长期会话过期恢复尚未验收 |

本仓库检查使用 `npm run check`；实际 App 桥接检查使用 `npm run test:app -- /明确选择的App路径`。站点 HTML、漫画图片、CF 凭据不进入仓库，测试仅保存合成数据。
