# RIDI

适配 `https://ridibooks.com` 的韩文漫画。热门、最新默认显示非成人条漫；搜索提供“条漫／漫画”分类，空搜索按所选分类浏览热门。列表使用官方公开 API，搜索使用网页声明的只读 GraphQL 查询：原始 HTML 是未筛选占位结果，分页按所选分类的计数判断，不采用包含小说等内容的全站总数。

作品身份为 `/books/<系列 ID>`，完整目录保留站点顺序、同名章节、番外和需要阅读权限的章节。初始目录只有部分章节，继续分页并核对归属、偏移和总数，全部成功才返回。章节 URL 使用 `/books/<章节 ID>/view#nodelane-ridibooks=<系列 ID>`；片段只在设备内绑定归属，正文再核对阅读器中的章节与系列 ID。网站只提供日期时按设备本地日历保留原日期，缺失或无效日期返回未知。

正文使用官方阅读器确认作品、章节及权限后取得 `comic` 图片清单，保留重复图片页槽。封面和正文接受接口返回的 HTTP(S) 地址，不限定 CDN 域名或路径模板。签名地址只交给 App 当次读取，不缓存、记录或分发。不以试读替代完整章节，不实现购买、领取限免、年龄验证或 DRM 解密。需要权限时提示用户在 RIDI 处理；设备 Cookie／UA 与验证入口由 App 管理，已购买账号会话兼容性尚未验收。

热门／最新每页一次 GET、最多 18 项；搜索每页一次 GET 和一次 GraphQL POST、最多 24 项。详情一次 GET 后顺序分页，每页最多 100 章、最多 100 次补页和 10000 章；正文一次 GET 和一次 JSON POST、最多 1500 张图片。列表页码上限 1000，响应上限 4 MiB；无预取、自动重试、跨调用目录缓存或动态下载脚本。错误区分验证、限流、权限、目录归属、目录完整性及图片格式。

```sh
npm run check
npm run test:app -- /明确选择的App路径
node scripts/verify-ridibooks.mjs
```

合成样本覆盖筛选分页、完整目录、重复章节、日期、归属、重复图片页槽、失败恢复与权限拒绝；实际 App QuickJS／DOM 桥已验证。真实 HTTP 已验证漫画／条漫搜索与分页、热门／最新、空结果，以及条漫和单行本的完整目录、正文与首尾图片；另抽查超过 100 章的目录补页和无权限章节的明确拒绝。源站偶发超时需要手动重试，不作为空结果保存。

iOS 模拟器已验证本地目录自动安装、图标、热门、完整详情与日期、正文首尾页、跨章、超时后手动重试和后台恢复的位置保持。模拟器搜索与筛选交互、真机、已购买账号会话、真实 CF 验证尚未验收，Android 暂缓。协议和图标来源见 [THIRD_PARTY.md](../../THIRD_PARTY.md)。
