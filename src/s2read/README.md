# S2READ

第二个模板验证站点，精确认领 `https://s2read.com/manga/<作品>/` 和其章节路径。独立实现当前 Madara HTML／只读 AJAX 协议，不声明其他 Madara 网站自动可用。

热门、最新和搜索每页一条 `madara_load_more` 只读 POST，固定每页 12 项，返回轻量候选。成功空响应或已知末页标记才代表结束；短页无标记、验证页、WordPress 错误和重复列表条目失败。详情一次 GET 读取完整静态目录；遇到未加载的 AJAX 目录明确失败。章节路径支持小数与下划线（如 `chapter-64.20`、`chapter-116_1`）。重复记录按规范化后的完整 URL 合并，保留首次出现的位置和日期；不同 URL 不按名称或编号合并，每条记录仍先检查作品归属。缺少可选封面不丢弃有效作品。

章节上传日期读取 `.chapter-release-date`，支持英语月名日期与秒／分／时／日／周的 `ago` 相对时间，返回毫秒字符串。日历日期保留设备本地的年月日，相对时间统一以本次解析时刻计算。缺失、非法或未知格式返回空字符串，不使用发现时间，也不让日期缺失导致整本目录失败。已有 App 需支持刷新时更新日期；旧书籍下拉刷新详情后才会纠正已存日期和补全目录。

正文一次 `?style=list` GET，核对 canonical、预填充导航与当前章节，图片槽必须连续，重复图片 URL 保留不同页位置。图片接受本站、`cdn.s2read.com` 及已发现的 `cdn-N`、`cdnN`、`vpsN` 数字子域，保留本站 Referer。旧 `http://cdn.s2read.com/` 地址改用已核验可用的同主机 HTTPS，路径、查询参数和页序保持不变；其他 HTTP、未知主机及相似域名仍拒绝，不猜测替换图片域名。故障带 `[S2:类型]`；身份核对通过但正文无图片时返回 `chapter-empty`，不返回空成功结果。

## 验证边界

| 层级 | 已验证 | 限制 |
| --- | --- | --- |
| Node 与 App QuickJS／DOM 桥 | 列表、完整目录、路径变体、归属、重复条目、图片顺序及日期；日期覆盖闰日、相对时间、未知值与上海／洛杉矶时区 | 合成样本不代替真实网站与设备会话 |
| 真实 HTTP | 热门／最新／搜索与空结果，多部作品完整目录、小数／下划线章节及图片清单；真实响应日期解析 | 有正文无图片的章节；`vps1.s2read.com`、`cdn2.s2read.com` 图片连接检查失败，解析支持不保证旧图片可下载 |
| iOS 27 模拟器 | 本地安装／更新、搜索／缺封面、完整目录及旧日期纠正；实际章节首尾页、下一章、后台和重进后位置保持；目录刷新保留已读标记 | 记录 ID、书签、重复刷新无新章通知由 App 入库测试覆盖；真实 CF、真机与性能尚未验收 |

## 检查入口

```sh
npm run check
npm run test:app -- /明确选择的App路径
node scripts/verify-s2read.mjs
# 串行抽查热门与最新首屏，最多 24 部目录，不下载图片：
node scripts/verify-s2read.mjs --catalogs
```

实现依据当前源站原始响应及浏览器项目的协议说明，未复制其适配器或共享引擎实现。未提取只有一个消费站点的通用 Madara 框架。来源记录见 [THIRD_PARTY.md](../../THIRD_PARTY.md)。
