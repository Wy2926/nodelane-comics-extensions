# S2READ

第二个模板验证站点，精确认领 `https://s2read.com/manga/<作品>/` 和其章节路径。独立实现当前 Madara HTML／只读 AJAX 协议，不声明其他 Madara 网站自动可用。

热门、最新和搜索每页一条 `madara_load_more` 只读 POST，固定每页 12 项，返回轻量候选。成功空响应或已知末页标记才代表结束；短页无标记、验证页、WordPress 错误和重复列表条目失败。详情一次 GET 读取完整静态目录；遇到未加载的 AJAX 目录明确失败。章节路径支持小数与下划线（如 `chapter-64.20`、`chapter-116_1`）。重复目录记录只按规范化后的完整 URL 合并，顺序保留首次出现的位置，不按章节名称或编号合并不同 URL；每条记录仍先检查作品归属。

正文一次 `?style=list` GET，核对 canonical、预填充导航与当前章节，图片槽必须连续，重复图片 URL 保留不同页位置。图片接受本站与已发现的 `cdn-N`、`cdnN`、`vpsN` 数字子域，保留本站 Referer，不猜测替换源站图片域名。故障带具体 `[S2:类型]` 便于定位；身份核对通过但正文没有图片时提示 `chapter-empty`，不再统称为结构变化，也不返回空成功结果。

真实 HTTP 已取得热门／搜索翻页、最新、空结果、955 条章节目录及测试章节 6 张图片清单。针对 0.1.1 的目录错误，抽查热门与最新共 24 部作品，其中 16 部因重复 URL 或章节路径变体失败；0.1.2 已通过这 16 份原响应回放和全部 24 部目录的真实 HTTP 复查，并取得小数／下划线章节的图片清单。样本中一个章节返回的正文确实没有图片；`vps1.s2read.com` 和 `cdn2.s2read.com` 的图片连接检查失败，解析支持不代表这些旧图片当前可下载。

iOS 27 模拟器已验证本地安装与 0.1.2 更新、搜索／缺封面占位、955 条目录、普通章节首尾页与下一章。配合 App 的章节入库修复，Under the Oak Tree 刷新后从 218 条恢复为 228 条；`Chapter 64.20` 实际图片可读，翻到第 3/35 页后，后台返回及退出重进都保留位置，本轮未新增错误报告。旧 App 按编号二次合并的行为需更新 App，已有作品需刷新详情才能补回目录。缺少可选封面不丢弃有效作品，正文缺图仍明确失败。单元样本与真实 App QuickJS／DOM 桥分别验证；CF、真机与性能尚未验收。没有因继承同类引擎而开放未核验变体。

```sh
npm run check
npm run test:app -- /明确选择的App路径
node scripts/verify-s2read.mjs
# 额外串行检查热门与最新首屏，最多 24 部目录；不下载图片：
node scripts/verify-s2read.mjs --catalogs
```

实现依据当前源站原始响应及浏览器项目的协议说明，未复制其适配器或共享引擎实现。未提取只有一个消费站点的通用 Madara 框架。来源记录见 [THIRD_PARTY.md](../../THIRD_PARTY.md)。
