# 少年ジャンプ＋

集英社日语漫画。JS 移植 Keiyoushi Shonen Jump+：热门为连载作品，最新按日本时区选取当日更新，关键词搜索按源站游标翻页。正文需要 App 的 `image.tile-transpose.v1`。

真实 HTTP 已核对热门、最新、两页搜索、空结果及只有单行本的作品。《SPY×FAMILY》的 184 个单话、18 卷与源站及原包一致；前两话分别为 71、55 页，均取得首尾 JPEG。Node 有搜索游标回归，App QuickJS 已验证连载列表。

默认目录保留付费番外和卷。若“阅读”或“下一章”选到付费卷，可在目录中直接选择公开单话；来源设置也可隐藏付费章节。付费或已停止公开的章节不会返回正文。

MuMu Android 12 x86_64 从本地目录安装 JS，断网打开《SPY×FAMILY》第 1 话显示重试，恢复网络后读到正文。《のろのろぷくぷく》第 1 话 `44 / 44` 可切到第 2 话并读到 `26 / 26`，退到桌面再打开保持 `14 / 26`。iOS、ARM 真机和离线下载未验收。
