# となりのヤングジャンプ

集英社日语页漫来源。复用 Keiyoushi Tonari no Young Jump 原包和 GigaViewer 图片处理；热门、最新、关键词搜索均由扩展返回单页。付费或不可用条目按源站权限处理。

MuMu Android 12 x86_64 的 NodeLane Mihon 桥已验证热门、最新、日语搜索与空结果。《ワンパンマン》目录含 286 个不同章节标识；抽查连续两话（22、16 页），在设备上取得首尾 JPEG。

修复版 App 使用同一原包，连续阅读模式从《ワンパンマン》第 288 话 `15 / 15` 切入第 289 话，短末页与读完提示同屏时显示 `16 / 16`；回到桌面再打开仍为第 289 话 `9 / 16`。iOS、ARM 真机及离线下载未验证。
