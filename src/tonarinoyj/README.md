# となりのヤングジャンプ

集英社日语页漫来源。复用 Keiyoushi Tonari no Young Jump 原包和 GigaViewer 图片处理；热门、最新、关键词搜索均由扩展返回单页。付费或不可用条目按源站权限处理。

MuMu Android 12 x86_64 的 NodeLane Mihon 桥已验证热门、最新、日语搜索与空结果。《ワンパンマン》目录含 286 个不同章节标识；抽查连续两话（22、16 页），在设备上取得首尾 JPEG。另从本地目录安装并在 App 阅读器打开热门作品第 1 话，可翻到 `66 / 66`。UI 跨章与后台恢复、iOS、ARM 真机和离线下载待验收。
