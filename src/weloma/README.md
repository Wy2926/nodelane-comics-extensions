# WeLoveManga（weloma.net）

JS 来源 `0.1.0`，永久 ID `86001012`。支持热门、最新、关键词搜索及分页、作品资料、网站当前公开的章节目录和正文图片。按本次要求采用 JS，参考 Keiyoushi WeLoveManga/FMReader，来源与许可见 [THIRD_PARTY](../../THIRD_PARTY.md)。

通过 App `Client` 与 DOM 桥读取 HTML，不执行网站脚本或保活 WebView。解码 Base64 UTF-8 标题和图片地址，图片使用章节 Referer；章节保留完整 URL、查询参数和作品归属标记，图片保留重复页槽。目录与阅读页菜单交叉核对，失败整体报错，重试重新请求。

网站部分长篇目前只公开最近 200 章，作品页、阅读菜单及最早可见章的导航一致；插件没有章数上限，也不推测未公开章节地址。返回的是网站公开目录，不保证全作品历史齐全。缺失或未知日期保持未知。

## 验证边界

- Node 回归与 App 实际 QuickJS／DOM 契约覆盖搜索分页、编码、目录归属、日期、重复页位、失败与重试。
- 桌面通过 App 实际 QuickJS／DOM／HTTPS 桥验证热门前两页（各 20 项）、最新、关键词搜索及空结果；列表重定向由宿主正常处理。抽查《PIRATE KING (MANGA)》公开目录 200 章，第 1198、1197、999 章分别返回 17、15、17 页，六张首尾图片携带章节 Referer 下载并经 ImageIO 完整解码。
- Android、iOS 模拟器／真机的安装、正文阅读、跨章、后台恢复与页码保持尚未验收；原版 APK 未作设备验收。

已启用并纳入正式目录，设备验收范围仍以上述说明为准。未提供高级筛选、账号登录或历史来源数据迁移。
